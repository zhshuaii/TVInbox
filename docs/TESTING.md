# 第一版真机验收

以下是待执行的检查项，不代表已完成的测试记录。记录电视型号、Android 版本、浏览器版本、源码提交和 APK 来源。

## 电视和安装

- [ ] TV Launcher 可见图标；主页面显示二维码、地址和列表。
- [ ] 遥控器可到达安装、删除、清空和退出，焦点清楚。
- [ ] 上传只增加列表项，不自动打开任何安装界面。
- [ ] 点击安装才打开系统原生安装器；未知来源授权返回后继续。
- [ ] 拒绝授权或取消安装不误报成功、不重复弹窗。
- [ ] 系统安装器使用中的文件不能被清理。
- [ ] 从安装器返回后能再次上传、安装或删除。
- [ ] 系统安装过程中重建进程、重开应用，不遗留无法清除的安装锁。
- [ ] 中文、空格、Unicode 与长文件名显示正常。
- [ ] 720p / 1080p / 4K 可见范围和焦点可用。

## 手机网页

- [ ] Android Chrome 和 iPhone Safari 的扫码、选择、上传、取消。
- [ ] 320 / 375 / 390 / 430 像素宽度无横向溢出。
- [ ] 没有远程安装、删除、电视文件列表或安装状态轮询。
- [ ] 发送进度 100% 时等待电视确认，不提前显示成功。
- [ ] 无效 APK、空文件和超限文件明确提示。
- [ ] 手机锁屏、切后台、断网、取消不遗留不断增长的残片。
- [ ] 断外网保留局域网仍可使用；电脑支持单文件拖入。

## 文件和网络

- [ ] 第 11 个文件或超过 512 MiB 的接收被拒绝。
- [ ] 磁盘不足明确提示，7 天过期包在下一次清理时删除。
- [ ] 两台手机只接受一个并行上传，清空跳过使用中的文件。
- [ ] 同名包不相互覆盖，重新打开恢复列表。
- [ ] 主端口被占用时二维码改用备用端口。
- [ ] 切换网线/Wi-Fi 或 IP 后更新二维码，退出后停服。
- [ ] HTTP 无目录遍历、APK 下载、远程安装和远程删除。
- [ ] 验证 APK 权限、体积、签名及 SHA-256。

自动 JVM / Web 测试不能代替以上真实设备验收。
