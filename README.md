# 轻收 · TVInbox

轻量 Android TV APK 收件箱：手机扫码上传，电视手动安装。

## 第一版范围

- 电视打开后显示局域网地址和二维码。
- 手机或电脑通过浏览器上传单个 APK，不使用令牌或 PIN。
- 上传完成只进入电视列表，不自动安装。
- 电视遥控器操作：安装、删除、清空安装包。
- 最多 10 个安装包、收件箱容量 512 MiB、保留 7 天。
- GitHub Actions 自动检查、编译并提供测试 APK。

应用包名：`io.github.zhshuaii.tvinbox`。

当前为项目初始化基线，完整实现通过独立分支和 Pull Request 提交。
